# مشروع تطبيق الخطة الشهرية للأنشطة

هذا الملف ZIP يحتوي **مشروع المصدر** وليس APK جاهزاً.

## الأسهل من الهاتف: ارفع ZIP واحداً
1. ارفع الملف `MonthlyPlanOfflineAndroid.zip` نفسه إلى جذر مستودع GitHub.
2. في GitHub اختر **Add file > Create new file**.
3. في خانة الاسم اكتب `.github/workflows/build.yml`.
4. افتح الملف `GITHUB_WORKFLOW_COPY.txt` الموجود داخل ZIP وانسخ كل محتواه إلى ملف GitHub الجديد، ثم اضغط **Commit changes**.
5. افتح تبويب **Actions**، اختر **Build Android APK from ZIP** ثم **Run workflow**.
6. بعد نجاح البناء، افتح التشغيل المكتمل ونزّل Artifact باسم `monthly-plan-debug-apk`.

## ميزات المشروع
- الصفحة الأصلية للخطة الشهرية داخل WebView.
- الإملاء العربي المحلي باستخدام Vosk بعد تنزيل النموذج أول مرة.
- حفظ PDF عبر نافذة الطباعة في Android، ثم اختيار Save as PDF.

## متطلبات أول استخدام للإملاء دون إنترنت
يحتاج التطبيق اتصالاً بالإنترنت مرة واحدة لتنزيل نموذج اللغة العربية، حجمه المنشور نحو 318 ميغابايت، مع مساحة إضافية لفك الضغط. بعد اكتمال التجهيز يمكن إجراء الإملاء دون إنترنت. يجب السماح باستخدام الميكروفون.

## تنبيه الاختبار
لم يتم بناء APK أو اختباره على هاتف فعلي بعد. لا يمكن ضمان خلوه من الأخطاء قبل نجاح البناء واختباره عملياً. بعد التنزيل اختبر فتح التطبيق، حفظ البيانات بعد إغلاقه، الإملاء بعد إيقاف الإنترنت، وتصدير PDF.
